# Support

## Questions and ideas

Ask questions in [GitHub Discussions](https://github.com/pipe1os/shipdot/discussions). Use the Q&A category for "how do I..." questions. Use the Ideas category for feature proposals.

## Bugs

Open an issue with the [bug report form](https://github.com/pipe1os/shipdot/issues/new/choose). Please include the versions of `shipdot`, `@shipdot/cli` and your browser, and a minimal `shipdot.json` or entry that reproduces the problem.

## Security issues

Never open a public issue for a security problem. Report it privately with [GitHub Private Vulnerability Reporting](https://github.com/pipe1os/shipdot/security/advisories/new). See [SECURITY.md](SECURITY.md) for more details.

## Documentation

Guides and reference are on the [docs site](https://pipe1os.github.io/shipdot/).
